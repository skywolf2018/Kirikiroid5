# Kirikiroid5 - 基于 Kirikiri 引擎的 Android 模拟器

**Kirikiroid5** 是一个在 Android 平台上运行 Kirikiri (吉里吉里) 引擎游戏的模拟器，基于老版 Krkr/Kirikiroid2 全面优化和重构而来。

---

## ✨ 主要特性

- **流畅运行 Kirikiri 游戏**：支持 `.xp3`、`startup.tjs`、`system.tjs` 等标准 Kirikiri 游戏格式
- **优化的启动体验**：5 秒启动动画 + 后台异步扫描，告别黑屏等待
- **智能游戏扫描**：首次扫描后自动缓存列表，二次打开秒加载
- **完整 Android 14 适配**：已适配 Android 11+ 存储权限（`MANAGE_EXTERNAL_STORAGE`）
- **SDL2 渲染加速**：基于 SDL2 底层渲染，支持硬件加速和 GLES 3.0 兼容
- **横屏游戏模式**：默认锁定横向，沉浸式游戏体验

---

## 🛠️ 本次优化亮点

| 优化项 | 说明 |

## 📥 安装使用

1. **下载 APK**：从 Releases 页面下载最新版本
2. **安装并授予权限**：首次启动自动请求“所有文件访问权限”
3. **放置游戏文件**：将包含 `data.xp3` 的游戏文件夹放入手机存储（如 `/sdcard/游戏名/`）
4. **打开应用**：自动扫描并显示游戏列表，点击即可运行

---

## ⚙️ 技术要求

- Android 7.0+ (API 24+)
- ARM64-v8a 架构设备
- 建议开启“所有文件访问权限”以扫描外部存储
